# 家庭影像 · Family Gallery（Project Two）

本地优先的**家庭照片/视频管理**：导入后**自动按时间、地点归类与汇总**，支持相册、收藏、私密区。
所有文件都存在本机（浏览器 IndexedDB），不联网、不上传。

> **本地 · 离线 · 按时间/地点归类 · 私密保护**

## 功能（第一版）

- 📥 **导入**：批量选择/拖拽照片视频；自动读取 **EXIF 拍摄时间**与 **GPS**，生成缩略图。
- 📊 **总览**：照片/视频数量、时间跨度、地点数、按年份分布。
- 🖼 **图库**：按「年-月」自动分组的网格；点开大图/视频查看（支持左右切换）。
- 📍 **地点**：按 GPS 自动聚类（约 1 公里），分组浏览；无定位的单独归类。
- 📁 **相册**：自建相册（导入时可归入）。
- 🔒 **私密区**：密码门保护的私人照片/视频；可在查看时一键设为私密。
- ⚙️ **设置**：深浅色、存储概览、清空、私密区密码重置。

## 运行

```bash
python run.py        # 或双击 start.bat（Windows）；浏览器打开 http://127.0.0.1:5181/
# 开发：npm install && npm run dev
```

仓库已内置打包好的 `dist/`，只装 Python 也能直接跑。

## 说明与隐私

- 照片/视频与缩略图保存在本机浏览器存储（IndexedDB），**不联网**。
- 「地点」默认只做坐标聚类，**不联网反查地名**（保护隐私）。
- 私密区当前为**访问密码保护**；文件级端到端加密为后续计划。

## 路线图

- 人物/人脸归类、按事件聚合、地图视图（离线瓦片）。
- 私密区文件级加密；可选联网反查地名（默认关闭）。
- 用 Tauri 打包为 Windows/macOS 本地应用（可直接访问磁盘大文件，免重复导入）。

技术栈：Vite + React 18 + TypeScript + exifr；纯前端、零后端。
