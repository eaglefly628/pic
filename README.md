# 我家里的一切

我们家所有应用的**统一入口**。一个入口、一个端口，进去后用顶部菜单选择进入各应用。
本地优先、注重隐私：数据都存在本机，不联网、不上传。

## 启动（唯一入口）

```bash
python run.py        # 或双击 start.bat（Windows）
# 浏览器打开 http://127.0.0.1:5180/ ，顶部菜单进入「家庭理财 / 家庭影像」
```

只需装 Python（各子应用已内置打包好的 `dist`，无需 Node）。

## 架构

- `hub/index.html`：统一入口页（品牌 + 顶部应用菜单 + 内容区）。
- `run.py`：统一服务器，按路径加载各应用的 `dist`：
  - `/` → 入口页　·　`/finance/*` → `project-one/dist`　·　`/gallery/*` → `project-two/dist`　·　`/vault/*` → `project-three/dist`　·　`/dev/*` → `project-four/dist`
- 各应用仍是**独立项目**（独立源码/构建/可单独打包），通过入口集成；新增应用只需：构建出 `dist`，在 `run.py` 的 `MOUNTS` 加一行、在 `hub/index.html` 加一个菜单/卡片。

> 单独开发某个应用：进入其目录 `npm run dev`（理财 5180 / 影像 5181 / 密码 5182 / 开发世界 5183 的开发端口）。
> 数据按浏览器来源（host:端口）隔离——统一入口都在 5180，请固定从这里进入。

## 设计原则

数据只存本机、不联网、不上传；敏感内容本地加密（理财主密码 / 影像私密区）。

### 任何操作都必须有可见反馈

这是所有应用共同遵守的交互硬规则：用户点击后，界面必须立即明确表示“已收到”，不能静默等待。

- 短操作显示进行中并禁用重复提交；成功或失败都要给出明确结果。
- 扫描、分析、导入、备份、整理等长任务必须显示状态、已完成/总量、进度条、当前对象、错误数；
  能估算时还要显示处理速度和剩余时间。
- 长任务必须支持安全暂停、断点续跑；刷新页面或重启服务后仍能从后端恢复真实状态。
- 危险操作使用页面内确认并写清影响范围，不依赖可能被浏览器拦截的原生弹窗。
- 前端显示必须以后端持久化状态为准；轮询不得因慢请求乱序而让进度倒退或长期停在 0。
