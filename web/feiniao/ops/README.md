# 飞鸟发布与迁移

当前实现：Sites Worker 提供密码访问、D1 云端加密记录和附件分块存储。新记录不写入 localStorage 或 IndexedDB。`public/` 是界面源码，`worker/` 是服务端源码；运行 `node scripts/build.mjs` 构建。旧版浏览器数据只能由用户在原浏览器点击“导出此浏览器的旧版记录”，再导入云端。

以下阿里云脚本与说明仅保留为历史部署参考，不适用于当前 Worker 云端数据库版本；阿里云尚未连接，不具备双站同步。

运行时密钥 `PASSWORD_HASH`、`PASSWORD_SALT` 和 `SESSION_SECRET` 通过 Sites 管理，不写入源码。访问密码参与浏览器端 PBKDF2/AES-GCM 加密；更换密码前必须先导出并重新加密全部数据，不可只替换服务端校验值。所有持有访问密码的人都能读写此私人空间。

云端加密文字库上限约 1.3 MB，超限保存会明确失败；附件每条数据库记录分成 500 KB 片段，附件库界面限制总计 150 MB。版本号比较保护并发保存。请定期导出独立加密备份；本数据库不会自动到期删除。快速整理使用常见中文表达规则提取，字段可修改，完整原文保留，不依赖外部 AI 服务。

## 已具备的部署步骤

同一份 dist 是 Sites 与阿里云的发布输入。部署脚本计算每个文件的 SHA-256，以内容摘要生成不可变版本目录；上传并校验后再切换 current 链接，保留此前的 releases 以供回退。首次部署前必须检查 ECS/轻量服务器现有站点，配置独立目录、部署用户权限、可信 HTTPS 与服务器指纹。

将 deploy.example.json 复制到本机配置文件，填写已验证的 SSH Host 别名、网站目录与 HTTPS 地址。不得把私钥、服务器密码、AccessKey 或主密码放进配置文件或仓库。

检查计划：node ops/deploy-aliyun.mjs --config ops/deploy.local.json --dry-run

部署前端：node ops/deploy-aliyun.mjs --config ops/deploy.local.json

Sites 端仍通过 Sites 的原生保存与发布流程部署同一版本，保留其项目身份和私密访问设置。发布后核对两端的版本与文件摘要；任何一端失败都应明确显示，不能声称双端原子发布成功。

## 跨站数据同步待接通

目标：两个前端共用阿里云上的加密数据服务。个人内容、账号与媒体先在浏览器加密，再传输密文。服务端需要鉴权、版本号比较、冲突处理、独立备份与 HTTPS。页面和功能同版与数据实时同步是两件独立的事；当前只完成前端部署准备，尚未部署该服务。

所需信息：实例公网 IP、操作系统、地域、已验证的 SSH 登录方式，以及可用的可信 HTTPS 地址。不需要通过聊天发送服务器密码或私钥。

## 本地内容与备份

文字、账号与附件索引保存在 localStorage 的加密数据中；图片、音频和视频使用 IndexedDB 保存密文。导出备份会合并所有被记录或锁定草稿引用的加密附件。恢复时需要原主密码。

更换网址、浏览器或设备不会自动带走数据。清除任一浏览器存储之前，先保存编辑内容并导出完整加密备份。主密码无法找回。

主密码至少 8 字符。图片单文件 10 MB、音频 25 MB、视频 50 MB，每篇最多 10 个附件，总计 100 MB；当前浏览器附件库总计最多 150 MB。云端大容量上传需要接通服务器后扩展。

## 独立运行

以 dist 为根目录运行静态服务器即可。开发可使用 localhost；正式环境必须使用可信 HTTPS，浏览器加密与媒体功能才可正常工作。仅复制网页源码不包含用户的浏览器数据。

## 统一添加与富文本编辑

所有新建入口进入“添加 · 智能入口”，根据表达和已有记录的相似度建议类型、主题、标题、标签和账号字段；字段可手动改动，原文保存在加密记录的 sourceText。没有外部大模型请求或额外 API 密钥。分类拿不准时存到随手记，用户可以后续修改。

编辑器使用本地打包的 TipTap，document 保存可编辑 JSON，body 保留纯文本供搜索和旧记录兼容，appearance 保存页面背景。图片、音频、视频仍由云端加密附件接口读写，富文本节点仅保存附件 ID 和位置，不保存临时 blob URL。旧记录首次编辑时转换为富文本，云端备份同时包含格式。

验证：node tests/editor.test.mjs；node tests/cloud.test.mjs。构建：npm run build。发布包包括 .openai/hosting.json、dist/server 和 drizzle（含 meta/_journal.json）。

## 独立创作工作台与行业观察

record.studio 保存创作方式、诗笺主题、全局字体、行距字距、留白、作者、副标题、导语、封面/背景附件ID和词牌草稿。现代诗回车换行、Shift+回车分节；没有古典平仄评分。词牌仅校验六个明确版本，数据来源见 /credits.txt；缺字、多读和异读保留待确认状态。诗笺SVG/PNG采用整页文字设置，不嵌入正文局部富文本或音视频。

编辑闲置8秒自动将结构化草稿加密写入云端，显式保存后成为作品。自动草稿不会新增已完成记录。

行业观察另用 industry_items / industry_runs / industry_settings 表；主 vault 的加密记录没有改动或重建。网页接口要求访问密码会话，定时写工具要求站点所有者的 Sites 身份。定时部署和验证步骤见 industry-schedule.md。
