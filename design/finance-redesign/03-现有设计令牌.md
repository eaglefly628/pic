## 三、语义颜色约定（全站一致，**这套要保留**）

| 场景 | 颜色 |

| 负数 / 支出 / 负债 | `var(--red)` |

## 六、碎片化统计（这就是要收敛的东西）

- **圆角 6 档**：`6 / 7 / 8 / 9 / 13 / 14`
- **字号 9 档**：`10.5 / 11 / 11.5 / 12 / 12.5 / 13 / 13.5 / 14 / 15`
- **控件高度 4 档**：`30`（工具条）/ `34`（按钮）/ `36`（输入）/ `52`（工具条与侧栏头）
- **卡片内边距**：各页不一（`22` 最常见，但弹窗正文是 `18px 22px`，空态是 `48px 22px`，表头是 `7~8px 22px`）
- **边框粗细**：几乎全是 `0.5px`（Retina 下的发丝线），少数 `2px`（滚动条 thumb 的透明边）

## 八、其他已经做对的细节（别删）

```css
/* 自定义滚动条：9px，thumb 用 --separator-strong，2px 透明边做内缩 */
.fv-scroll::-webkit-scrollbar { width: 9px; height: 9px; }

/* 原生控件跟随明暗 */
.fv-root[data-theme="light"] { color-scheme: light; }
.fv-root[data-theme="dark"]  { color-scheme: dark; }
/* 深色下 select option 显式上色，否则浅底浅字看不清 */
.fv-root select option { background: var(--bg-card); color: var(--text-primary); }

/* 键盘可达性：仅键盘聚焦才显示描边环 */
.fv-root :focus-visible { outline: 2px solid var(--accent); outline-offset: 2px; }
.fv-root :focus:not(:focus-visible) { outline: none; }
```
