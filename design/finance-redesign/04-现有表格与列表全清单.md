## 先看这个：全局规律

### 数字格式化函数（`lib/format.ts`）

| 函数 | 输出样例 | 说明 |
|---|---|---|
| `fmt(n)` | `¥1,234` / `−¥1,234` | 取整，负号用 U+2212 `−` 不是 hyphen |
| `fmtWan(n)` | `¥12.3万`（\|n\|≥10000）否则 `¥1,234` | 最多 1 位小数，图表 Y 轴专用 |
| `fmtSigned(n)` | `+¥1,234` / `−¥1,234` | 永远带符号，"较上次"类列专用 |
| `fmtPct(frac, digits=1)` | `12.3%` | |

> 财经行情页**自己另有**一个同名 `fmt`（`Markets.tsx:15`），不带货币符号，空值返回 `—`。跟上面这个不是一回事。

### 分类名（`compute.ts:9-16`，所有分组表头都用它）

固定顺序：`流动资金` → `投资理财` → `家庭房产` → `家庭其他固定资产` → `负债`

### 颜色约定（全站一致）

| 场景 | 颜色 |
|---|---|
| 负数 / 支出 / 负债 | `var(--red)` |
| 正数 / 收入 / 增长 | `var(--green)` |
| 零变化 / 无数据 | `var(--text-tertiary)` |
| 账户 56 天没更新（stale） | `var(--orange)` |
| 账户超 30 天没更新（overdue） | 红字 + 红色 15% 底的「超时更新」角标 |

### 表头行样式（有表头的那几张都长一样）

`fontSize: 11` · `color: var(--text-tertiary)` · `background: var(--bg-card-2)` · `padding: 7~8px 22px`

## 1. 仪表盘（Dashboard.tsx）

### 1.1 顶部三张指标卡（非表格，`repeat(3,1fr)` gap 16）

| 卡 | 标题 | 主数值 | 副标签 |
|---|---|---|---|
| 1 | `总资产` | `fmt(assetsRaw)` | `资产合计` · `{N} 个账户`，绿 |
| 2 | `总负债` | `fmt(liabRaw)` | `含信用卡/贷款` · `负债合计`，红 |
| 3 | `净资产`（渐变卡） | `fmt(net)` 27/700 | `fmtSigned(netDelta)` · `较上期`，白字 |

### 1.2 「每月变化量」柱状行

- 标题 `每月变化量`，右挂灰色小字 `近 12 期净资产变化`
- 近 12 期，**按时间正序**（左旧右新），不可切换
- 每列自上而下：备注按钮（或 `＋`）→ 变化数值 → 柱子 → 月份 `YY/MM`
- 柱子：宽 58%（上限 30px），高 `max(4, ratio×56)`，圆角 4
- 数值文案：`+¥12.3万` / `−¥8,000`（`fmtWan`，正数手动加 `+`）
- 颜色：`delta >= 0` 绿，否则红；**正在编辑那一列变成 accent 蓝**
- **交互**：点备注（或 `＋`，`title="标主要原因"`，透明度 0.35）→ 下方展开输入条，标题 `「{YY/MM}」主要原因`，输入框 placeholder `手动输入，如：发年终奖 / 股市回调 / 买房首付`，按钮 `保存` / `取消`。Enter 保存、Esc 取消，**存空字符串 = 删除该备注**，无二次确认
- 无数据时整张卡不渲染（没有空态文案）

### 1.3 「净资产趋势」折线图

- 标题 `净资产趋势`，副标题三选一：`最近 3 个月 · 按月快照` / `最近 12 个月 · 按月快照` / `全部历史 · {YYYY-MM} 至今`
- 区间切换 `Segmented` 宽 212：`近3月` / `近1年` / `全部`，**默认 `近1年`**
- Y 轴 4 条网格线用 `fmtWan`，X 轴约 6 个 `YY/MM`
- Hover 提示：ISO 日期（10.5 灰）+ `fmt(值)`（13/700）

### 1.4 「资产构成」环形图 + 图例列表

- 标题 `资产构成`；圆心默认显示 `占比`，hover 某段时换成该段百分比（18/700）+ 名称（10.5 灰，最宽 84 省略）
- 图例每行三列：**色点 9×9 圆角3** → **名称**（次级色，省略号）→ **百分比**（`marginLeft:auto` 右对齐，主色 600 tabular）
- 百分比 = `fmtPct(该项 / 总资产)`，1 位小数
- **排序**：按金额倒序；**分组**：按账户的 `comp` 字段归类，落空归入 `其他`；余额 ≤ 0 的账户不参与
- **交互**：hover 图例行 ↔ hover 圆弧 双向联动高亮（选中弧 strokeWidth 15→21，其余降到 13 且透明度 0.4）。**不可点击**
- 配色固定：房产 `#007AFF`、股票 `#34C759`、理财/固收 `#FF9500`、基金 `#5E5CE6`、现金及银行 `#FF2D55`、黄金 `#FFD60A`、养老金 `#5AC8FA`、公积金 `#AF52DE`、其他固定资产 `#A2845E`、其他 `#8E8E93`
- 无合计行、无空态

### 1.5 「最近更新」列表 —— 无表头

标题 `最近更新`；行 `padding: 11px 22px`，上边框 0.5px 分隔线，**整行可点**

| # | 列 | 宽 | 内容 |
|---|---|---|---|
| 1 | 图标块 | 34×34 圆角9 | 12×12 色点，底色为账户色 16% 透明 |
| 2 | 名称 | 自适应 | 账户名（13/500）/ 下方 `{日期} · 月末盘点`（11.5 灰） |
| 3 | 金额 | `marginLeft:auto` 右对齐 | `fmt(当前值)`（13.5/600）/ 下方 `fmtSigned(变化)`（11/600） |

- **排序**：所有账户算出「较上一期变化」，剔除变化为 0 的，按**变化绝对值倒序**，取前 4 条。不可切换
- 变化颜色：`>= 0` 绿，`< 0` 红
- **交互**：点整行 → 跳该账户详情页。无编辑、无删除
- **空态**：`暂无变动记录`（12.5 灰，`padding: 0 22px 18px`）

- 三个 tab 底部各有一段说明，都以 ` 本页需要联网。` 结尾

## 13. 重构时值得一并解决的不一致

按值不值得动手排序：

1. **只有 4 张结构有表头行** —— 余额快照、利息预测、收入。而 **预算的开销列表列宽节奏几乎一样（90/110/130/70）却没有表头**，这是最扎眼的一处不一致。密码、备份、信息字段也都没有表头。
2. **只有 1 张表有合计行**（利息预测）。收入、开销的合计被放在了上方的指标卡里，两套做法并存。
3. **删除行为极不统一**：余额快照有二次确认；收入、开销、密码、个人信息**全是点了就删**；设置里的备份则恢复和删除都确认。导入 Excel 会替换全部账户和快照，同样**没有确认**。
4. **零状态覆盖不全**：收入、开销、密码、信息、备份、利息都有空态文案，但**资金账户列表和余额快照没有** —— 零数据时是一片空白。
5. **利息表合计行的颜色规则和它自己的数据行不一致**：数据行有「零值显示灰色」，合计行只有红/绿。
6. **`来源` 列恒为「导入」**（`compute.ts:354` 三元两分支相同），手动新增的快照也会被误标。
7. **密码列表的分类列会塌陷** —— 没填分类时该列整个不渲染，导致同一张列表里各行的列位置对不齐。
8. 排序能力分布很散：账户有 3 种模式可切；利息、最近更新、资产构成是写死的排序；收入、开销就是**数组插入顺序**，多了以后没法整理。
