# 男主的开发世界 · Dev World

本地优先、**主密码加密**的个人工作台：任务看板、笔记本、代码片段、书签，一个主密码管住全部。
数据只存本机（IndexedDB，AES‑256 加密），不联网、不上传。是「我家里的一切」门户下的一个独立应用。

## 功能

- **概览**：问候 + 快速记任务 + 统计卡（未完成/今日逾期/笔记/片段）+ 进行中任务 / 最近笔记 / 常用书签
- **任务**：看板三列（待办 / 进行中 / 已完成），优先级、到期日（今天/逾期高亮）、标签，左右键流转
- **笔记**：双栏笔记本，搜索、分类、标签、置顶、防抖自动保存（方便迁移 OneNote 内容）
- **片段**：代码 / 命令片段，语言标签、一键复制、标签、搜索
- **书签**：按分类分组，字母头像 + 站点名，新标签页打开
- **设置**：自动锁定、导出/导入加密文件（多机迁移）、修改主密码

## 开发 / 构建

```bash
npm install
npm run dev      # 开发端口 5183
npm run build    # 产出 dist/（已相对路径打包，供统一入口 /dev/ 挂载）
```

> 统一入口：仓库根 `python run.py` → http://127.0.0.1:5180/ ，顶部「开发世界」。
> 加密说明：主密码经 PBKDF2‑SHA256 派生密钥、AES‑256‑GCM 加密整库；主密码不保存、不上传，遗失无法找回。
