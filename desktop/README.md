# 「我家里的一切」Mac 安装版（Electron）

把整个大厅（理财 / 影像 / 密码 / 开发世界）打成一个双击就用的 Mac App。
数据仍然全部存在你本机、加密、不上传；App 只是个原生外壳，后端用的还是仓库里的 `run.py`。

> 说明：代码构建必须在 **你的 Mac 上**跑一次（苹果的 `.app/.dmg` 只能在 macOS 上生成、签名）。
> 下面一共两条命令。

## 一次性准备

需要 **Node.js 18+** 和 **Python 3**（你平时就有）。检查：

```bash
node -v && python3 --version
```

## 构建

在仓库根目录：

```bash
cd desktop
npm install          # 第一次会下载 Electron，约几十 MB
npm run mac          # 出成品
```

完成后，安装包在 `desktop/release/` 里：

- `我家里的一切-0.2.0.dmg` —— 双击打开，把图标拖进「应用程序」即安装。
- （也会有一个 `.zip`，等价，随便用一个。）

## 首次打开（未签名，属正常）

这个包没有花钱做苹果签名，所以第一次打开 macOS 会拦一下。**右键点 App 图标 →「打开」→ 再点「打开」**，之后就能像普通 App 一样双击用了。

## 把你现在的数据搬进去（一次性）

新 App 第一次跑起来时：

- 如果本机备份目录是空的，它会**自动**恢复上次的数据；
- 否则，在旧的浏览器页面点「设置 · 数据 → 导出全部」得到一个 `.home` 文件，
  再到新 App 里「设置 · 数据 → 整屋备份 → 从备份恢复…」选它。30 秒。

之后就不用管了：App 每隔一会儿、每次关闭都会自动把全屋数据存到
`~/Library/Application Support/我家里的一切/`（保留最近 40 份历史），换新版本也照样读得到。

## 改版本号

只改仓库根目录的 `VERSION` 文件（比如 `0.3.0`）。`npm run mac` 会自动把它同步到 App 和
`run.py` 的 `/api/version`。备份文件里带 `appVersion`，格式向前兼容，新版本能读旧数据。

## 它到底做了什么

`main.js` 启动时：找到你的 Python → 拉起 `run.py`（`HOME_NO_BROWSER=1`，不再另开系统浏览器）
→ 等 `localhost:5180` 就绪 → 用一个原生窗口打开它。关窗即退出、顺带停掉后端。
