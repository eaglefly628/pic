# 家庭密码 · Family Vault

本地优先、**零知识加密**的全家密码保险库：网站账号、银行卡、安全笔记、家庭信息，
**一个主密码**管住全部。数据只存本机，不联网、不上传。

## 用法

从统一入口进入（推荐）：仓库根目录 `python run.py` → 顶部「家庭密码」。
或单独开发：`npm install && npm run dev`（开发端口 5182）。

- **首次**：创建主密码（至少 8 位）。主密码是唯一钥匙，**不保存、不可找回**，请牢记。
- **日常**：解锁后新建/编辑「登录 / 银行卡 / 安全笔记 / 家庭信息」；
  支持强密码生成、两步验证码（2FA / TOTP）、一键复制（约 25 秒后自动清空剪贴板）、闲置自动锁定。
- **多机共享**：设置 →「导出加密文件」，把 `.vault` 文件拷到另一台机器 →「导入」→ 用主密码解锁。

## 安全模型

- 主密码经 **PBKDF2-SHA256（60 万次迭代）** 派生密钥；
- 整个保险库用 **AES-256-GCM** 加密后存入浏览器 IndexedDB；明文只在内存中存在；
- 导出的文件即上述加密密文，没有主密码无法解开；
- 全程本地，无网络请求、无遥测。

> 提醒：请牢记主密码并定期「导出」备份；遗失主密码＝数据无法恢复。
